# Asgarrd 릴리즈 노트

## 2026-10-21

### 이번 배포 요약

- 직원이 메일 화면에서 예전 메일 서비스의 메일을 직접 가져오고 진행 상황을 확인할 수 있습니다.
- 메일 주소를 정하지 않은 구성원에게 안내 메일을 자동으로 보내고, 메일 설정과 도메인 연결 화면을 단계별로 정리했습니다.
- 일정 상세에 등록 정보와 원래 일정을 보여 주고, 일정 끌어 옮기기와 반복 일정 변경을 개선했습니다.
- 메일 탭에서 로그인 창이 뜨던 문제와 데스크톱 앱의 업무 기록 중지 문제를 수정했습니다.

### `feature`

**예전 메일 직접 가져오기:** 직원이 메일 화면의 「예전 메일 가져오기」에서 이전 메일 서비스의 백업 파일을 올려 메일을 직접 옮길 수 있습니다. 옮긴 메일 수와 옮기지 못한 메일을 확인하고 실패한 메일은 다시 시도할 수 있으며, 이미 옮긴 메일은 건너뜁니다.

**직원별 예전 메일 현황:** 관리자는 메일 설정과 구성원 주소 화면에서 직원별 예전 메일 가져오기 상태를 보고, 필요한 직원에게 안내를 보낼 수 있습니다.

**메일 주소 안내 자동 발송:** 회사 메일 주소를 아직 정하지 않은 구성원에게 안내 메일이 자동으로 발송됩니다. 관리자는 특정 구성원에게 다시 알릴 수 있고, 초대를 다시 보내면 유효 기간이 7일로 늘어납니다.

**일정 등록 정보와 원래 일정:** 일정 상세에서 등록한 사람과 등록 시각을 볼 수 있습니다. 놓친 일정을 다시 잡은 경우 원래 일정이 함께 표시되고, 눌러서 바로 이동할 수 있습니다.

### `change`

**메일 화면 구성:** 메일 왼쪽 메뉴에 관리 영역이 생겨, 관리자는 주소를 정하지 않은 구성원 수와 메일 설정의 할 일을 바로 볼 수 있습니다. 이전 메일 서비스에서 가져온 메일은 「이전 메일함」에 따로 모아 보여 줍니다.

**메일 설정과 구성원 주소 화면:** 발신 인증 값을 넣으면 확인 결과가 자동으로 갱신되고, 수신 전환 진행 단계를 한 화면에서 따라갈 수 있습니다. 구성원 주소 화면에서 주소를 정한 사람 수와 상태별 구성원 목록을 확인할 수 있습니다.

**도메인 연결:** 회사 도메인 연결을 도메인 입력, 구입한 곳 선택, 소유 확인, 연결 확인의 4단계로 정리했습니다.

**회원가입:** 가입 화면에 비밀번호 확인 칸을 추가해 두 비밀번호가 다르면 바로 알려 줍니다. 가입·초대 수락·로그인 화면의 디자인도 새로 바꿨습니다.

**반복 일정 변경:** 반복 일정의 반복 빈도를 바꾸면 따로 수정해 둔 회차가 새 규칙에 맞게 초기화되며, 저장 전에 이를 안내합니다.

**일정 끌어 옮기기:** 일정을 끌어 놓으면 바로 새 자리에 표시되고, 화면 끝으로 끌면 자동으로 스크롤됩니다.

### `fixed`

**메일 탭 로그인 창:** 메일 탭에서 브라우저 로그인 창이 뜨고 취소하면 홈으로 이동하던 문제를 수정했습니다. 메일 서버에 연결하지 못하면 화면 안에 안내와 「다시 시도」 버튼을 보여 줍니다.

**예전 메일 폴더:** 백업을 가져올 때 받은 편지함·보낸 편지함의 메일이 이전 메일함으로 들어가거나, 영문 이름의 폴더가 제자리로 옮겨지지 않던 문제를 수정했습니다.

**메일 이관 완료:** 옮기지 못한 메일을 「옮기지 않기」로 처리한 뒤에도 이관이 다음 단계로 넘어가지 않던 문제를 수정했습니다.

**옮긴 일정의 참석 기록:** 참석을 기록한 일정을 앞으로의 시각으로 옮겨도 "참석 완료"가 남던 문제를 수정했습니다.

**일정 홈 주간 목록:** 끝난 회의가 같은 회의의 팀 일정으로 주간 목록에 다시 보이던 문제를 수정했습니다.

**일정 오류 안내:** 일정 화면에 영문 오류 문구가 그대로 보이던 문제를 수정했습니다. 불러오기에 실패하면 「다시 시도」 버튼을 보여 줍니다.

**업무 기록 중지:** 데스크톱 앱에서 기록을 시작하거나 일시정지하는 도중에 중지하면 기록이 계속되던 문제를 수정했습니다.

**macOS 창 버튼:** 데스크톱 앱의 창 닫기·최소화·확대 버튼이 왼쪽 메뉴 경계에 걸쳐 보이던 문제를 수정했습니다.
