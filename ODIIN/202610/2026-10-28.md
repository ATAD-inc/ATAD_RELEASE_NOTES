# ODiiN 릴리즈 노트

## 2026-10-28

### 이번 배포 요약

- Azure PostgreSQL 유연한 서버·DocumentDB, 백업/복구, Event Grid·Service Bus·API Management를 새로 지원합니다.
- AWS Secrets Manager, EventBridge 규칙, SES 구성 세트, API Gateway 사용자 지정 도메인·사용량 계획, ElastiCache Valkey·Memcached 캐시를 관리할 수 있습니다.
- GCP Kubernetes Engine, Memorystore for Valkey, BigQuery 예약된 쿼리·작업 탐색기·워크로드 관리를 이용할 수 있습니다.
- 클라우드 연동 목록에서 계정 정보와 접근 상태를 바로 확인하고, AWS 작업 이력을 조회할 수 있습니다.

### `feature`

**Azure PostgreSQL 유연한 서버:** 데이터베이스 메뉴에서 PostgreSQL 유연한 서버를 조회하고 만들 수 있습니다. 서버 상세에서 네트워킹, 데이터베이스, 서버 매개 변수, 백업을 관리할 수 있습니다.

**Azure DocumentDB:** MongoDB 호환 DocumentDB 클러스터를 만들고 방화벽·프라이빗 엔드포인트 같은 네트워킹 설정을 관리할 수 있습니다. 읽기 복제본, 암호화, 메트릭과 진단 설정도 지원합니다.

**Azure 백업/복구:** 새 백업/복구 메뉴에서 보호 항목, 백업 작업, 보호 정책, 자격 증명 모음을 관리할 수 있습니다. 백업을 구성하고 지금 백업하거나 복원할 수 있으며, 실패한 작업의 오류와 권장 조치를 확인할 수 있습니다.

**Azure Event Grid:** 통합 메뉴에서 Event Grid 토픽, 도메인, 네임스페이스, 시스템 토픽을 조회·생성하고 이벤트 구독을 관리할 수 있습니다.

**Azure Service Bus:** 네임스페이스와 큐·토픽·구독을 조회·생성·관리할 수 있습니다. 메시지 탐색기로 큐와 구독의 메시지를 확인할 수 있습니다.

**Azure API Management:** API Management 서비스를 조회·생성하고 API와 정책, 제품, 구독과 키를 관리할 수 있습니다.

**AWS Secrets Manager:** 보안 암호를 조회하고 만들 수 있습니다. 값과 교체 설정을 바꾸고, 다른 리전에 복제하거나 삭제를 예약할 수 있습니다.

**AWS EventBridge 규칙:** 규칙을 조회·생성·편집·삭제하고 켜거나 끌 수 있습니다. 이벤트 패턴, 대상, 재시도 정책을 설정할 수 있습니다.

**AWS SES 구성 세트:** 구성 세트를 조회·생성·삭제하고 옵션을 편집할 수 있습니다. 이벤트 대상을 추가·편집하고 켜거나 끌 수 있습니다.

**AWS API Gateway:** API Gateway 메뉴에서 사용자 지정 도메인 이름과 사용량 계획을 관리할 수 있습니다. 인증서를 골라 도메인을 추가하고 API 매핑을 설정할 수 있습니다.

**AWS ElastiCache 캐시:** ElastiCache 메뉴에서 Valkey와 Memcached 캐시를 조회·생성·수정할 수 있습니다. 노드와 백업을 관리하고 메트릭을 확인할 수 있습니다.

**GCP Kubernetes Engine:** Kubernetes 클러스터를 조회하고 Autopilot 또는 Standard 방식으로 만들 수 있습니다. 클러스터 상세에서 노드 풀과 예상 월 비용을 확인하고, 보안 비밀과 ConfigMap을 YAML로 수정하거나 삭제할 수 있습니다.

**GCP Memorystore for Valkey:** Valkey 인스턴스를 조회·생성·수정·삭제하고 ACL 정책을 관리할 수 있습니다.

**GCP BigQuery 예약된 쿼리와 작업 탐색기:** 예약된 쿼리를 조회·생성·수정·삭제하고 실행 기록을 확인할 수 있습니다. 작업 탐색기에서 프로젝트의 쿼리 작업 내역을 볼 수 있습니다.

**GCP BigQuery 워크로드 관리:** 슬롯 예약과 약정, 할당을 조회·생성·수정할 수 있습니다. 필요한 슬롯 수를 미리 가늠해 볼 수도 있습니다.

**AWS 작업 이력:** 클라우드 연동 화면에서 AWS 계정에 수행된 작업 이력을 기간·작업·결과별로 조회하고 CSV로 내려받을 수 있습니다.

### `change`

**클라우드 연동 목록:** 상세를 열지 않아도 목록에서 AWS 계정 번호, GCP 프로젝트 ID, Azure 구독 ID와 접근 상태를 확인하고 별칭을 바로 수정할 수 있습니다. 접근 상태 확인은 GCP·Azure 계정에서도 지원합니다.

**AWS 자동 연동 흐름:** AWS 연동 화면이 자동 연동 탭으로 바로 열리고, 연동이 끝나면 안내와 함께 클라우드 목록으로 이동합니다. 연동을 취소해도 자동 연동 탭에서 바로 다시 시작할 수 있습니다.

**템플릿 내보내기:** Azure Key Vault·Front Door·Event Grid의 템플릿을 매개 변수 없이 내보낼 수 있습니다.

### `fixed`

**로그아웃 후 다시 로그인:** 로그아웃하거나 세션이 만료된 뒤 다시 로그인하면 이전에 선택했던 클라우드 계정 때문에 오류가 나던 문제를 수정했습니다.

**로그인 인증번호 시간:** 인증번호 메일을 확인하려고 다른 탭이나 앱으로 이동하면 남은 시간 표시가 멈추던 문제를 수정했습니다.

**Azure 가상 네트워크 새로 고침:** 가상 네트워크 상세의 새로 고침 버튼이 최신 정보를 불러오지 않던 문제를 수정했습니다.

**네트워크 ACL 규칙:** 네트워크 ACL 규칙의 유형·프로토콜·포트 범위가 화면 언어로 표시되지 않던 문제를 수정했습니다.
