# ODiiN 릴리즈 노트

## 2026-10-07

### 이번 배포 요약

- 이메일 인증번호 로그인과 복구 이메일을 도입하고, 회원가입·사업자 정보 관리 흐름을 개선했습니다.
- AWS의 서버리스·컨테이너·배포·백업 관리와 Azure·GCP의 클라우드 관리 범위를 넓혔습니다.
- 실시간 알림과 알림별 화면 이동을 지원하고, 청구서·크레딧 화면을 정리했습니다.
- 챗봇의 화면 이동 안내와 대화 표시를 개선했습니다.

### `feature`

**복구 이메일:** 가입할 때 복구 이메일을 인증해 등록할 수 있습니다. 로그인 인증번호를 받기 어려울 때 복구 이메일로 받을 수 있습니다.

**사업자 전환과 서류 관리:** 개인 회원이 설정에서 사업자 정보와 첨부 서류를 등록해 사업자 회원으로 전환할 수 있습니다. 등록된 사업자 정보와 첨부 서류도 확인하고 수정·삭제할 수 있습니다.

**실시간 알림:** 새 알림과 읽지 않은 알림 수를 실시간으로 확인할 수 있습니다. 알림에서 관련 화면으로 이동하고, 설정에서 알림 유형별 수신 여부를 바꿀 수 있습니다.

**AWS CloudFront:** 배포 목록과 상세를 조회하고, 배포 생성·설정 변경·캐시 무효화를 할 수 있습니다. 원본, 캐시 동작, 오류 페이지, 정책과 원본 액세스 설정을 관리할 수 있습니다.

**AWS Lambda:** 함수와 애플리케이션을 조회하고, 함수를 생성하거나 설정을 변경할 수 있습니다. 대시보드에서 사용 현황을 확인하고 이벤트 소스 매핑을 관리할 수 있습니다.

**AWS ECR:** 프라이빗·퍼블릭 리포지토리와 이미지를 조회하고, 리포지토리 생성·삭제와 정책·태그 관리를 할 수 있습니다.

**AWS ECS:** 클러스터를 조회·생성하고, 클러스터 안의 서비스와 태스크를 확인할 수 있습니다. 서비스 생성과 태스크 실행을 지원합니다.

**AWS CodeBuild:** 빌드 프로젝트를 생성하고 프로젝트 정보, 빌드·배치 이력, 로그, 보고서와 지표를 확인할 수 있습니다. 빌드 실행과 재정의 설정을 지원하며, 지원되지 않는 설정은 화면에서 안내합니다.

**AWS CodeDeploy:** 애플리케이션, 배포 구성, 온프레미스 인스턴스를 조회하고 관리할 수 있습니다. 배포 상태와 개정 정보를 확인하고 지원되는 배포를 다시 시도할 수 있습니다.

**AWS OpenSearch:** 도메인 정보와 모니터링 지표, 예약 인스턴스, VPC 엔드포인트를 조회할 수 있습니다. 도메인에 연결된 패키지와 태그도 확인할 수 있습니다.

**AWS Backup:** 백업 계획과 볼트, 보호된 리소스, 백업·복원·복사 작업을 확인할 수 있습니다. 백업 계획 설정과 복구 시점을 관리하고 백업·복원 작업을 실행할 수 있습니다.

**AWS SES:** 계정의 발송 한도·사용량·평판 지표와 이메일 템플릿 목록을 확인할 수 있습니다. 전용 IP와 IP 풀을 조회하고 관리할 수 있습니다.

**Azure DNS:** 공용·프라이빗 DNS 영역과 레코드를 조회·생성·수정·삭제할 수 있습니다. 프라이빗 DNS 영역의 가상 네트워크 연결도 관리할 수 있습니다.

**Azure SQL:** SQL 데이터베이스, 논리 서버와 탄력적 풀을 조회하고 생성할 수 있습니다. 리소스의 태그도 수정할 수 있습니다.

**Azure MySQL:** 유연한 서버의 생성·복원과 설정 변경을 지원합니다. 백업, 복제본과 네트워크 설정을 관리하고 작업 진행 상태를 확인할 수 있습니다.

**Azure 부하 분산 장치:** 부하 분산 장치를 조회·생성하고 구성과 태그를 변경할 수 있습니다.

**Azure 스토리지:** 스토리지 계정과 Blob 컨테이너를 조회하고 관리할 수 있습니다. 파일 공유에서는 공유 설정, 스냅샷과 프라이빗 엔드포인트 연결을 관리할 수 있습니다.

**GCP Cloud DNS:** DNS 영역과 레코드, DNS 정책과 응답 정책을 조회하고 관리할 수 있습니다.

**GCP API Gateway:** API, API 구성과 게이트웨이를 조회·생성하고 관리할 수 있습니다. API 구성에 등록된 사양 파일도 확인할 수 있습니다.

**GCP 서비스 계정:** 서비스 계정의 생성·수정·활성화·비활성화와 키 관리를 지원합니다. 서비스 계정과 프로젝트에 부여된 역할을 확인하고 변경할 수 있습니다.

**GCP Pub/Sub 스냅샷:** 스냅샷을 조회·생성·삭제하고 라벨을 수정할 수 있습니다. 구독의 메시지 처리 시점을 스냅샷 기준으로 되돌릴 수 있습니다.

**GCP 백업 및 DR:** 보호되는 리소스 목록과 백업 구성 상태를 확인할 수 있습니다.

**GCP VPC 경로:** 경로 목록과 상세를 조회하고 경로를 생성·삭제할 수 있습니다.

### `change`

**이메일 인증번호 로그인:** 비밀번호를 입력하는 대신 이메일로 받은 인증번호로 로그인하도록 변경했습니다. 인증번호 재전송과 복구 이메일 수신을 로그인 화면에서 진행할 수 있습니다.

**회원가입 절차:** 회원 유형을 개인·사업자로 정리하고, 비밀번호 입력 대신 닉네임과 인증된 복구 이메일을 등록하도록 바꿨습니다. 사업자는 업태와 상세 업종을 선택할 수 있습니다.

**사업자 정보 입력:** 국세청 사업자 상태 확인 절차를 없애고 사업자 정보 입력과 서류 첨부 방식으로 변경했습니다.

**청구서와 크레딧:** AWS·Azure·GCP에서 공통 구성의 청구서·크레딧 화면을 이용할 수 있습니다. 청구서에서 클라우드별 사용 내역과 결제 상태를 확인할 수 있도록 정리했습니다.

**클라우드 연동 안내:** AWS·Azure·GCP 연동 가이드를 갱신했습니다. 안내 이미지를 확대해 볼 수 있고, GCP Cloud Shell 안내에서는 서비스 계정을 생성하는 스크립트를 제공합니다.

**Azure 메뉴:** Microsoft Entra ID와 PostgreSQL 유연한 서버 메뉴를 표시하지 않도록 변경했습니다. 해당 리소스는 Azure 포털에서 관리할 수 있습니다.

**챗봇 화면 이동:** Azure·GCP와 새로 지원하는 AWS 관리 화면으로 이동하는 안내 범위를 넓혔습니다. 제안서 검토 화면으로 이어지는 안내도 개선했습니다.

### `fixed`

**사업자 서류 업로드:** 로그인한 사용자가 사업자 서류를 첨부할 때 인증 오류로 업로드하지 못하던 문제를 수정했습니다.

**멤버 초대 실패 안내:** 멤버 초대가 실패하면 대상과 실패 사유를 확인할 수 있도록 개선했습니다.

**챗봇 대화 표시:** 답변에 내부 처리용 문구가 섞여 보이거나 대화 간 표시 상태가 간섭하던 문제를 수정했습니다. 답변이 끝난 뒤 입력창으로 돌아오는 동작도 개선했습니다.

**다국어 표시:** 영어·일본어 화면의 일부 항목이 번역 문구 대신 키 이름으로 표시되던 문제를 수정했습니다.

**클라우드 연결 오류 처리:** 클라우드 자격 증명 오류가 발생했을 때 ODiiN 계정까지 로그아웃되던 문제를 수정했습니다.

**네트워크 인터페이스 삭제:** 삭제가 실패했을 때 사유를 알 수 없던 문제를 수정하고, 연결 대상 표시를 바로잡았습니다.
