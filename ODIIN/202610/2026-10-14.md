# ODiiN 릴리즈 노트

## 2026-10-14

### 이번 배포 요약

- AWS 계정을 콘솔 로그인과 스택 생성만으로 연결하는 자동 연동을 열고, 클라우드 연동 화면을 개선했습니다.
- AWS CodePipeline·DocumentDB·SNS·EventBridge Scheduler와 SES 관리 기능, Azure 컨테이너 레지스트리·컨테이너 인스턴스를 새로 지원합니다.
- Azure 리소스 작업의 진행 상태 안내와 GCP·Azure 홈의 비용 표시를 개선했습니다.
- 청구서 표시와 수동 결제를 개선하고, 클라우드 연동 해제 오류를 수정했습니다.

### `feature`

**AWS 자동 연동:** 클라우드 연동 화면의 자동 연동 탭에서 AWS 계정으로 로그인하고 스택을 만들면, 권한 확인을 거쳐 읽기 전용으로 계정을 연동할 수 있습니다. 회사 SSO를 쓰는 경우 SSO 포털에서 먼저 로그인하도록 안내합니다.

**AWS CodePipeline:** 파이프라인 목록과 상세를 조회하고, 파이프라인 생성·편집·복제와 변경 사항 릴리스·중지·재실행·롤백을 할 수 있습니다. 실행 기록과 실행별 작업 내역·변수를 확인하고 트리거와 태그를 관리할 수 있습니다.

**AWS DocumentDB:** 클러스터를 생성·수정하고 인스턴스 추가, 시작·중지, 특정 시점 복원을 할 수 있습니다. 클러스터 스냅샷의 생성·복원·복사·공유와 서브넷 그룹·파라미터 그룹 관리, 이벤트 조회를 지원합니다.

**AWS SNS 구독:** 구독 목록을 조회하고 프로토콜별 구독 생성, 필터 정책·재드라이브 정책 편집, 구독 확인·삭제를 할 수 있습니다. SMS 구독에 쓸 샌드박스 전화번호도 추가할 수 있습니다.

**AWS EventBridge Scheduler:** 일정 그룹을 조회·생성·삭제하고 태그를 관리할 수 있습니다.

**AWS SES 자격 증명과 수신 관리:** 이메일·도메인 자격 증명을 조회·생성·편집·삭제할 수 있습니다. 금지 목록 주소 추가·제거와 대량 작업, 계정 수준 금지 설정, 수신 엔드포인트와 이메일 수신 규칙 세트 조회, SMTP 자격 증명 생성을 지원합니다.

**Azure 컨테이너 레지스트리:** 레지스트리를 만들고 리포지토리, 액세스 키, 캐시 규칙, 웹후크, 토큰과 범위 맵을 관리할 수 있습니다. 네트워크 접근과 프라이빗 엔드포인트 연결, 관리 ID, 지역 복제, 작업과 에이전트 풀, 일시 삭제 보존 기간도 설정할 수 있습니다.

**Azure 컨테이너 인스턴스:** 컨테이너 그룹을 만들고 시작·다시 시작·중지하며 로그와 메트릭을 확인할 수 있습니다. 만들 때 고객 관리형 키, 사용자 할당 관리 ID, 위임 서브넷이 있는 가상 네트워크, Log Analytics 작업 영역을 함께 설정할 수 있고, 연결 탭에서 컨테이너 셸에 접속할 수 있습니다.

### `change`

**클라우드 연동 명령:** AWS·Azure·GCP의 CLI 연동을 Cloud Shell에 붙여넣는 한 줄 명령으로 바꾸고, 가이드 화면에 실행할 명령을 함께 보여 줍니다. GCP 연동 명령은 필요한 API를 자동으로 켜고, 결제 계정이 연결되지 않은 프로젝트도 연동을 마칠 수 있습니다.

**클라우드 연동 화면:** 연동 화면에서 다른 클라우드 연동으로 바로 이동할 수 있습니다. GCP·Azure도 여러 계정을 연동할 수 있고, 연동 계정 상세에서 AWS 계정 번호와 Azure 클라이언트 ID·구독 ID를 확인할 수 있습니다.

**Azure 작업 진행 안내:** 가상 머신, 가상 머신 확장 집합, VM 이미지 버전, SQL, 부하 분산 장치, 사설 DNS 영역, 리소스 그룹, 스토리지 계정 작업을 접수한 뒤 진행 상태를 안내합니다. 같은 리소스에 진행 중인 작업이 있으면 사유를 알려 줍니다.

**GCP·Azure 홈 비용:** GCP·Azure 홈의 비용 위젯과 월 비용에 실제 사용 비용을 청구 통화로 표시합니다.

**청구서 표시:** 청구서 품목과 이월 감액을 나눠 표시하고, 각주에 플랫폼 이용 수수료율을 적습니다. 금액에 천 단위 구분 기호를 넣었으며, 0.50달러 미만의 소액 청구는 다음 달로 이월됩니다.

### `fixed`

**청구서 수동 결제:** 수동 결제가 완료되지 않던 문제를 수정했습니다. 청구서를 한 건씩 카드로 결제할 수 있고, 보유 크레딧은 결제 때 먼저 적용됩니다. 일부 연체 청구서는 자동 결제로 안내합니다.

**클라우드 연동 해제:** AWS·Azure 계정의 연동 해제가 실패하던 문제와, 다시 연동한 계정을 해제할 때 오류가 나던 문제를 수정했습니다. 해제한 계정의 별칭을 다른 계정에 다시 쓸 수 있습니다.

**연동일 표시:** 연동 계정의 연동일이 표시되지 않던 문제를 수정했습니다.

**MSP 초대 가입:** MSP 초대 링크로 가입할 때 일반 회원 유형이 함께 표시되던 문제를 수정해 사업자 회원으로만 가입하도록 했습니다.

### `removed`

**Azure 결제 내역 메뉴:** Azure 결제 메뉴에서 결제 내역 항목을 내렸습니다. 결제 상태는 청구서 메뉴에서 확인할 수 있습니다.
