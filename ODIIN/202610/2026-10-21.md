# ODiiN 릴리즈 노트

## 2026-10-21

### 이번 배포 요약

- Azure Key Vault와 Front Door, AWS CloudFormation 스택을 새로 지원합니다.
- AWS SNS 주제·EventBridge 이벤트 버스·CodeDeploy 배포·OpenSearch 패키지·ElastiCache 관리 기능을 더했습니다.
- GCP 부하 분산과 BigQuery 스튜디오·데이터 전송을 이용할 수 있습니다.
- 알림과 AWS·Azure 화면이 영어·일본어로 더 정확하게 표시되고, 대시보드와 회원가입 이메일 인증을 개선했습니다.

### `feature`

**Azure Key Vault:** 보안 메뉴에서 키 자격 증명 모음을 조회·생성·삭제하고 네트워킹, 액세스 정책, 진단 설정을 관리할 수 있습니다. 키·비밀·인증서를 만들거나 새 버전을 추가하고, 메트릭과 템플릿 내보내기를 확인할 수 있습니다.

**Azure Front Door:** 콘텐츠 배달 메뉴에서 Front Door 프로필을 조회하고 생성할 수 있습니다. 엔드포인트·경로, 도메인, 원본 그룹, 규칙 집합, 인증서를 관리하고 캐시 제거와 보고서·메트릭·로그 확인을 지원합니다.

**AWS CloudFormation 스택:** 스택 목록을 조회하고 템플릿 파일이나 S3 URL로 스택을 만들 수 있습니다. 스택 상세에서 이벤트·리소스·출력·파라미터·템플릿을 확인하고, 업데이트 전에 변경될 리소스를 미리 본 뒤 스택을 수정하거나 삭제할 수 있습니다.

**AWS SNS 주제:** 주제를 조회·생성·편집·삭제하고 액세스 정책, 암호화, 태그, 구독을 확인할 수 있습니다. 주제에 메시지를 직접 게시할 수도 있습니다.

**AWS EventBridge 이벤트 버스:** 이벤트 버스를 조회·생성·편집·삭제하고 규칙, 아카이브, 권한 정책을 확인할 수 있습니다. 이벤트 전송과 스키마 검색 설정도 지원합니다.

**AWS CodeDeploy 배포:** 배포 메뉴에서 계정·리전의 배포 전체를 조회하고, 배포를 생성·중지·재시도·복사할 수 있습니다. 배포 상세에서 실패 사유, 진행률, 대상 인스턴스별 수명 주기 이벤트와 로그를 확인할 수 있습니다.

**AWS OpenSearch 패키지:** 패키지를 조회하고 S3에서 가져오거나 업데이트할 수 있습니다. 버전 기록과 연결된 도메인을 확인하고, 도메인 연결과 업데이트 적용을 할 수 있습니다.

**AWS ElastiCache:** ElastiCache 메뉴에서 서브넷 그룹과 파라미터 그룹을 조회·생성·수정·삭제하고 이벤트를 확인할 수 있습니다.

**GCP 부하 분산:** 부하 분산기를 조회하고 구성 마법사로 생성·수정·삭제할 수 있습니다. 백엔드 서비스와 백엔드 버킷도 생성·수정·삭제할 수 있습니다.

**GCP BigQuery 스튜디오:** 데이터 세트와 테이블을 조회·생성·삭제하고 스키마와 데이터 미리보기를 확인할 수 있습니다. 쿼리 편집기에서 처리 예상량을 확인하고 쿼리를 실행하거나 뷰로 저장할 수 있습니다.

**GCP BigQuery 데이터 전송:** 전송 구성을 조회·생성·수정·삭제하고 지금 실행하거나 다시 시도할 수 있습니다. 실행 기록과 실행 로그를 확인할 수 있습니다.

### `change`

**알림 언어:** 알림 목록과 실시간 알림이 화면 언어(한국어·영어·일본어)로 표시되고, 언어를 바꾸면 바로 반영됩니다.

**영어·일본어 화면:** AWS·Azure 화면의 상태 값, 날짜, 남아 있던 한국어 문구를 화면 언어에 맞게 표시합니다. 영어·일본어 화면에서 삭제를 확인할 때도 그 언어로 확인어를 입력하면 됩니다.

**회원가입 이메일 인증:** 가입 중 이메일과 사업자번호를 바로 고칠 수 있고, 인증번호 6자리를 입력하면 자동으로 확인합니다. 이메일을 바꿔도 이미 인증한 복구 이메일은 유지됩니다.

**AI 리포트 자동화 실패 안내:** 자동화 적용이나 롤백이 실패하면 대상 리소스 삭제, 권한 부족 같은 원인을 알기 쉽게 안내합니다.

**첫 연동 직후 대시보드:** 아직 데이터가 없는 계정은 빈 차트 대신 안내 문구를 보여 줍니다.

### `fixed`

**대시보드 메모리·디스크:** AWS 대시보드 리소스 상태에서 VM 메모리·디스크가 N/A로 표시되던 문제를 수정했습니다.

**연동 후 계정 목록:** 새로 연동한 계정이 새로고침 전까지 계정 선택 목록에 나타나지 않던 문제를 수정했습니다.

**계정 선택:** SES·SNS·EventBridge 화면에서 상단 계정 선택이 비활성화되고 계정 이름이 비어 보이던 문제를 수정했습니다.

**IAM 사용자·역할 생성:** 생성 도중 화면 언어를 바꾸면 단계 화면이 비던 문제와, 영어·일본어 화면에서 정책 유형 필터를 걸면 목록이 비던 문제를 수정했습니다.

**S3 수명 주기 규칙:** 영어·일본어 화면에서 일부 스토리지 클래스로 전환 규칙을 만들 때 잘못된 값이 저장되던 문제를 수정했습니다.

**서브넷 라우팅:** 서브넷 상세의 라우팅 탭에서 NAT 게이트웨이·전송 게이트웨이 대상 경로가 오류로 표시되던 문제를 수정했습니다.

**최근 접속일:** 멤버 정보 수정 창의 최근 접속일이 실제 마지막 접속 시각으로 표시됩니다.

**Azure 상세 패널:** 상세 패널의 왼쪽 메뉴가 길 때 아래 항목이 잘려 보이던 문제를 수정했습니다.
