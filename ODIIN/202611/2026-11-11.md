# ODiiN 릴리즈 노트

## 2026-11-11

### 이번 배포 요약

- MSP에 원격 서포트를 요청하거나 MSP의 요청을 승인해, 내 ODiiN 화면에서 함께 문제를 해결할 수 있습니다.
- AWS WAF, EKS, DynamoDB, Redshift를 새로 관리할 수 있고, API Gateway·ECS·CodeBuild·ElastiCache·EventBridge 기능이 늘었습니다.
- Azure App Service, Container Apps, Kubernetes 클러스터, Managed Redis, Cosmos DB, WAF 정책, Data Explorer, Synapse Analytics를 지원합니다.
- GCP Cloud Storage, Cloud SQL, Cloud Run, Cloud CDN, Cloud Armor, Cloud Build, Filestore, Backup and DR 등 메뉴가 크게 늘었습니다.

### `feature`

**원격 서포트:** 연결된 MSP에 원격 서포트를 요청하거나, MSP가 보낸 서포트 요청을 확인하고 승인·거절할 수 있습니다. 승인하면 MSP 담당자가 내 ODiiN 화면을 함께 보며 작업을 도와줍니다.

**서포트 기록:** 새 서포트 메뉴에서 끝난 원격 서포트의 날짜별 목록과 참여자, 작업 기록, 주요 활동, 대화 내용을 확인할 수 있습니다.

**AWS 조직 계정 한 번에 연동:** AWS 자동 연동을 마치면 같은 조직의 다른 계정 목록이 표시되고, 최대 20개까지 골라 한 번에 연동할 수 있습니다. 클라우드 연동 목록에서는 하위 계정이 관리 계정 아래에 묶여 보입니다.

**클라우드 사용자 가져오기:** 연동한 AWS·GCP·Azure 계정에서 사용자를 찾아 ODiiN 멤버로 미리 등록할 수 있습니다. 등록된 사용자는 첫 로그인 때 가입을 마치면 바로 이용할 수 있습니다.

**AWS WAF:** 보호 팩(웹 ACL), IP 세트, 정규식 패턴 세트, 규칙 그룹을 조회·생성·수정·삭제할 수 있습니다. 보호 팩에는 관리형 규칙 그룹을 추가하고 보호할 리소스를 연결할 수 있습니다.

**AWS EKS:** EKS 클러스터를 조회하고 만들 수 있습니다. 클러스터 상세에서 노드 그룹, 추가 기능, 액세스 설정과 Kubernetes 리소스를 확인할 수 있습니다.

**AWS DynamoDB:** 테이블을 조회·생성·관리하고, 항목 탐색에서 테이블의 항목을 조회하고 추가할 수 있습니다.

**AWS Redshift:** 쿼리 편집기에서 쿼리를 실행하고 저장된 쿼리, 노트북, 차트, 실행 기록을 관리할 수 있습니다. 예약 쿼리와 스냅샷도 조회·관리할 수 있습니다.

**AWS API Gateway 확장:** API 목록과 REST·HTTP·WebSocket API 상세, VPC 링크, API 키를 관리할 수 있습니다.

**AWS ECS 태스크 정의:** 태스크 정의를 조회·등록·삭제할 수 있습니다.

**AWS CodeBuild 빌드 프로젝트:** 빌드 프로젝트를 만들고 편집·복제할 수 있으며, 설정을 바꿔 빌드를 시작할 수 있습니다.

**AWS ElastiCache Redis OSS:** Redis OSS 캐시를 조회·생성·수정하고, 캐시 백업을 따로 모아 생성·복사·내보내기·복원할 수 있습니다.

**AWS EventBridge Scheduler 일정:** 일정을 조회·생성할 수 있고, 일정을 만들 때 필요한 실행 역할을 새로 만들 수 있습니다.

**Azure App Service:** 웹앱을 조회·생성·배포하고 액세스 제한, 자동 크기 조정, 진단 설정을 관리할 수 있습니다.

**Azure Container Apps와 Kubernetes 클러스터:** 컨테이너 메뉴에서 Container Apps와 Kubernetes 클러스터(AKS)를 조회·생성하고 수정 버전, 노드 풀 등을 관리할 수 있습니다.

**Azure Managed Redis와 Cosmos DB:** 데이터베이스 메뉴에서 Managed Redis와 Cosmos DB 계정을 조회·생성하고, 네트워킹과 모니터링 설정을 관리할 수 있습니다.

**Azure WAF 정책:** 보안 메뉴에서 Application Gateway와 Front Door WAF 정책을 조회·생성하고 사용자 지정 규칙과 제외 항목을 관리할 수 있습니다.

**Azure 분석:** 새 분석 메뉴에서 Data Explorer 클러스터와 Synapse Analytics 작업 영역을 조회·생성·관리할 수 있습니다.

**GCP Cloud Storage와 Cloud SQL:** Cloud Storage 버킷을 조회·생성하고 폴더와 객체를 관리할 수 있습니다. Cloud SQL 인스턴스와 백업을 조회·생성하고 백업으로 복원할 수 있습니다.

**GCP Cloud Run:** Cloud Run 서비스, 작업, 작업자 풀, 도메인 매핑을 조회·생성·수정할 수 있습니다.

**GCP Kubernetes Engine 확장:** 워크로드, 게이트웨이·서비스·인그레스, 저장용량(영구 볼륨 클레임·스토리지 클래스)을 조회하고 관리할 수 있습니다.

**GCP 네트워크 서비스와 보안:** Cloud CDN 원본을 만들고 캐시를 무효화할 수 있습니다. 새 네트워크 보안 메뉴에서 DDoS 대시보드를 확인하고 Cloud Armor 보안 정책과 규칙을 관리할 수 있습니다.

**GCP Pub/Sub:** 주제, 구독, 스키마를 조회·생성·관리할 수 있습니다. 주제에 메시지 변환 코드를 붙이고 AI로 초안을 만들어 시험해 볼 수도 있습니다.

**GCP Cloud Build:** 대시보드, 빌드 기록, 저장소, 트리거, 권한 메뉴에서 빌드 현황을 확인하고 저장소 연결과 트리거를 관리할 수 있습니다.

**GCP 스토리지와 백업:** Filestore 인스턴스와 백업을 관리할 수 있습니다. Backup and DR에서 보호되지 않은 리소스, 백업 볼트, 백업 계획, 볼트에 저장된 백업을 확인하고 관리할 수 있습니다.

**GCP Memorystore 확장:** Redis 클러스터, Redis 인스턴스, Memcached 인스턴스, Valkey 백업을 조회·생성·관리할 수 있습니다.

### `change`

**왼쪽 메뉴 순서:** AWS, Azure, GCP의 왼쪽 메뉴 순서를 각 클라우드 콘솔과 비슷하게 정리했습니다.

**자동 연동 진행 표시:** 자동 연동 중 서버가 진행한 세부 단계가 진행 기록에 표시됩니다. 이미 연동된 Azure 구독과 GCP 프로젝트는 고를 수 없게 회색으로 표시됩니다.

### `fixed`

**연동일 표시:** 연동을 해제한 뒤 다시 연동한 계정의 연동일이 처음 연동한 날짜로 표시되던 문제를 수정했습니다. 이제 가장 최근 연동일이 표시됩니다.

**연동 해제 안내:** 클라우드 연동 해제 창의 안내를 실제 동작에 맞게 고쳤습니다. 해제한 계정은 다시 연동할 수 있으며, 이때 인증을 다시 해야 합니다.
