# ODiiN 릴리즈 노트

## 2026-11-18

### 이번 배포 요약

- 원격 서포트 중에 MSP 담당자와 화상·음성으로 통화하고, 끝난 서포트의 녹화를 다시 보거나 MP4로 내려받을 수 있습니다.
- 비용 대시보드를 클라우드별로 볼 수 있고, 홈과 이번 달 사용량에서 청구 단계와 사용료 구성을 더 자세히 확인할 수 있습니다.
- Azure 구독과 경로 테이블, GCP 로그 라우터·Cloud VPN·IAM 리소스 관리·감사 로그를 새로 관리할 수 있습니다.
- AWS SES, CloudFormation, CloudFront, CodeBuild, CodeDeploy, Lambda, OpenSearch, ECS, EKS 등에서 할 수 있는 작업이 늘었습니다.

### `feature`

**원격 서포트 화상·음성 통화:** 원격 서포트 중에 MSP 담당자와 화상·음성으로 통화할 수 있습니다. 참여 전에 마이크와 카메라를 고르고, 통화 중에도 켜고 끌 수 있습니다.

**서포트 녹화 다시 보기와 내려받기:** 끝난 서포트의 녹화를 통화 음성·영상과 함께 다시 볼 수 있고, MP4 파일로 내려받을 수 있습니다.

**작업 이력 통합:** 작업 이력에서 AWS·Azure·GCP 기록을 탭별로 보거나 「전체」 탭에서 한 목록으로 볼 수 있고, CSV로 내려받을 수 있습니다.

**멤버별 연동 계정 보기:** 멤버 관리에서 멤버 행을 펼치면 그 멤버가 접근할 수 있는 클라우드 계정과 접근 상태를 확인할 수 있습니다.

**소유자 위임:** 조직 소유자는 다른 멤버에게 소유자 권한을 넘길 수 있습니다. 넘기기 전에 바뀌는 권한을 비교해 확인할 수 있습니다.

**연동 계정 정보 최신화:** 클라우드 연동 목록에서 계정별 결제 카드 끝 4자리와 만료월을 확인하고, 계정 정보를 행별로 또는 한꺼번에 최신화할 수 있습니다.

**클라우드별 비용 대시보드:** 비용 대시보드에서 클라우드와 청구 기간을 골라 요약, 일별·월별 비용, 서비스별 비용을 볼 수 있습니다.

**홈 청구 카드:** 홈의 청구 및 결제 카드에 청구서 단계(집계 중, 결제 대기, 미납)가 표시되고, 미납이면 바로 결제할 수 있습니다.

**이번 달 사용량 구성:** 이번 달 사용량에서 클라우드 사용료, 관리 수수료, 이월 금액과 청구 금액에 포함되지 않는 직접 결제 사용료를 나눠 볼 수 있습니다.

**Azure 구독:** 새 청구 단위 메뉴에서 구독 목록과 이번 달 비용을 확인할 수 있습니다. 구독 상세에서 리소스 공급자 등록, 사용량·할당량 확인과 상향 요청, 태그 편집, 이름 바꾸기, 구독 취소를 할 수 있습니다.

**Azure 경로 테이블:** 새 네트워크 경로 메뉴에서 경로 테이블을 조회·생성·삭제하고, 경로와 서브넷 연결, 태그, 액세스 제어를 관리할 수 있습니다.

**GCP 로그 라우터:** 새 로깅 메뉴에서 로그 싱크를 조회·생성·수정·삭제할 수 있습니다. 로그 버킷, BigQuery 데이터 세트, Cloud Storage 버킷, Pub/Sub 주제로 로그를 보낼 수 있습니다.

**GCP Cloud VPN:** 새 네트워크 연결 메뉴에서 Cloud VPN 게이트웨이와 피어 VPN 게이트웨이를 조회·생성·삭제할 수 있습니다.

**GCP IAM 리소스 관리:** 조직의 프로젝트와 폴더를 조회·생성하고, 프로젝트 이동, 삭제·복원, 라벨 수정, 권한 관리를 할 수 있습니다.

**GCP IAM 감사 로그:** 프로젝트의 서비스별 감사 로그 구성과 상위 폴더·조직에서 물려받은 구성을 확인하고, 설정을 바꿔 저장할 수 있습니다.

**AWS SES 설정 시작과 수신 규칙:** 새 설정 시작 메뉴에서 프로덕션 액세스를 요청할 수 있습니다. 이메일 수신 규칙을 생성·수정·삭제하고 순서를 바꿀 수 있으며, IP 필터도 관리할 수 있습니다.

**AWS CloudFormation 확장:** 스택 종료 방지를 설정하고, 실패한 업데이트의 롤백을 계속 진행할 수 있습니다. 리소스별 드리프트 결과 확인과 리소스 가져오기도 지원합니다.

**AWS CloudFront 확장:** 배포에 여러 신뢰할 수 있는 키 그룹을 연결하고, 액세스 로그 설정을 편집할 수 있습니다. 스테이징 배포와 Anycast 고정 IP 목록도 만들 수 있습니다.

**AWS CodeBuild·CodeDeploy·CodePipeline 확장:** 빌드 프로젝트와 파이프라인의 알림 규칙을 관리하고, 빌드 배치 상세를 확인할 수 있습니다. 배포 그룹을 만들 때 블루/그린, 로드 밸런서, 롤백을 설정할 수 있고, 파이프라인을 특정 커밋으로 실행할 수 있습니다.

**AWS Lambda·OpenSearch 확장:** Lambda 함수에 계층, RDS 프록시, SnapStart, 실행 역할을 설정할 수 있습니다. OpenSearch 도메인을 만들고 버전을 업그레이드할 수 있으며, 원격 연결과 패키지 연결도 지원합니다.

**AWS ECS·EKS 확장:** ECS 클러스터를 만들 때 로그 그룹, Cloud Map 네임스페이스, 인스턴스 역할을 함께 만들 수 있습니다. EKS에서는 외부 클러스터 등록 해제, 액세스 정책 제거, Marketplace 추가 기능 설치를 할 수 있습니다.

**AWS DocumentDB·ElastiCache·ECR 등 기능 추가:** DocumentDB 서버리스 용량 범위 설정, ElastiCache Valkey 상세 지표, Secrets Manager 복제본 제거, ECR 이미지 서명 상태 확인과 아카이브, AWS Backup 볼트·계획 생성을 지원합니다.

### `change`

**결제 정책 반영:** 청구서는 매월 20일에 발행되고 25일에 자동 결제됩니다. 크레딧 화면에서 가장 가까운 만료일과 금액을 확인할 수 있습니다.

**결제 내역 메뉴 통합:** 결제 내역은 청구서 화면에서 확인합니다. 클라우드를 연동하지 않아도 청구서와 크레딧 화면을 열 수 있습니다.

**멤버별 클라우드 권한 적용:** 멤버는 소유자가 권한을 준 클라우드 계정만 보고 선택할 수 있습니다.

**원격 서포트 중 보호:** 서포트가 진행되는 동안 다른 탭에는 잠금 안내가 표시되고, 서포트 중인 클라우드 계정은 다른 멤버가 변경할 수 없습니다. 서포트 화면은 서포트마다 따로 암호화해 전달합니다.

**Azure 작업 진행 알림:** 태그 저장, 백업 업로드, 역할 할당 등 Azure 작업 중에 진행 상태를 알려 주고, 끝나면 성공·실패를 안내합니다.

**GCP 서비스 연결 정책:** Filestore와 Memorystore for Valkey 인스턴스를 만드는 화면에서 서비스 연결 정책을 바로 만들 수 있습니다.

### `fixed`

**비용 화면 조회 지연:** 조직 비용을 불러오는 데 오래 걸리거나 실패하던 문제를 수정했습니다.

**청구 금액 불일치:** 홈, 청구서, 크레딧 화면에서 청구 금액이 서로 다르게 보이던 문제를 수정했습니다.

**비용 차트 표시:** 비용 차트의 월 이름이 항상 영어로 나오고 툴팁이 카드 밖에서 잘리던 문제, 비용 분석에서 GCP·Azure 서비스가 모두 기타로 묶이던 문제를 수정했습니다.

**Azure 목록 검색·필터:** 여러 Azure 목록에서 검색어와 필터가 적용되지 않던 문제를 수정했습니다.

**Azure 진단 설정:** 진단 설정 조회·저장·삭제에 실패하면 이유를 표시하고, 최대 개수에 이르면 더 추가하지 못하게 했습니다.

**Azure 구독 비용 카드:** Azure 호출 한도 때문에 비용을 불러오지 못하면 다시 시도할 수 있게 안내합니다.

**AWS EC2 표시:** vCPU 수가 코어 수만으로 표시되던 문제와 VM 상세에서 자동 할당 IP와 탄력적 IP 라벨이 바뀌어 있던 문제를 수정했습니다.

**AWS 삭제 확인 단어:** IAM 사용자와 Auto Scaling 그룹을 삭제할 때 안내된 확인 단어와 실제로 입력해야 하는 단어가 다르던 문제를 수정했습니다.

**AWS 데이터베이스·메시징 오류:** DocumentDB 복원 때 일부 설정이 빠지던 문제, ElastiCache Valkey 백업 생성과 태그 저장 오류, SNS 구독 생성 오류, DynamoDB 테이블 상세의 설정 값 표시 문제를 수정했습니다.
