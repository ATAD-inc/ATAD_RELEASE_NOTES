# ODiiN 릴리즈 노트

## 2026-11-25

### 이번 배포 요약

- Azure 가상 네트워크 게이트웨이, 로컬 네트워크 게이트웨이, 연결, ExpressRoute 회로, 프라이빗 엔드포인트, Azure Firewall, App Service 요금제를 새로 관리할 수 있습니다.
- GCP 조직 정책을 확인하고 바꾸기 전에 시뮬레이션해 볼 수 있으며, Network Connectivity Center 허브와 스포크를 관리할 수 있습니다.
- 비용 대시보드에서 계정 하나의 비용만 골라 볼 수 있고, 청구 기간이 바뀌는 날에도 비용 차트가 자연스럽게 이어집니다.
- 로그인 후 화면이 더 빨리 열리고, 언어나 클라우드를 바꿔도 보던 화면과 입력한 값이 유지됩니다.

### `feature`

**Azure 가상 네트워크 게이트웨이:** 네트워크 경로 메뉴에서 VPN·ExpressRoute 게이트웨이를 조회·생성·삭제하고, 구성, 지점 및 사이트 간 설정, VPN 클라이언트, 태그, 역할 할당, 잠금을 관리할 수 있습니다. 오래 걸리는 작업도 끝날 때까지 지켜보다가 결과를 알려 줍니다.

**Azure 로컬 네트워크 게이트웨이와 연결:** 로컬 네트워크 게이트웨이를 관리하고, 게이트웨이 사이의 사이트 간 연결을 만들 수 있습니다. 연결 상세에서 구성, IPsec 정책, 인증, NAT 규칙, 태그를 관리하고 VPN 장치 구성 파일을 내려받을 수 있습니다.

**Azure ExpressRoute 회로:** ExpressRoute 회로를 조회·생성·삭제하고 피어링, 권한 부여, 진단, 메트릭과 태그를 관리할 수 있습니다.

**Azure 프라이빗 엔드포인트:** 프라이빗 엔드포인트를 조회·생성·삭제하고 DNS 구성과 태그를 관리할 수 있습니다. 목록에서 호스트 파일을 만들 수 있고, 만들 때 이미 사용 중인 고정 IP를 고르면 어떤 리소스가 쓰고 있는지 알려 줍니다.

**Azure Firewall:** 방화벽을 조회·생성·삭제하고 크기 조정, 규칙 컬렉션, SNAT 제외 범위, Route Server 연결, 진단 설정을 관리할 수 있습니다. 규칙에 IP 그룹을 지정하고, NAT 규칙의 변환 주소에 FQDN을 쓸 수 있으며, 패킷 캡처도 실행할 수 있습니다.

**Azure App Service 요금제:** 새 애플리케이션 메뉴에서 App Service 요금제를 조회·생성·삭제할 수 있습니다. 앱 다시 시작, 워커 재부팅, 리소스 그룹·구독 이동, 하이브리드 연결과 VNet 경로 관리, 자동 크기 조정 실행 기록과 알림 설정을 지원합니다.

**GCP 조직 정책:** IAM 메뉴에서 조직 정책과 보안 기준 충족 현황을 확인할 수 있습니다. 정책을 바꾸기 전에 시뮬레이션을 실행해 위반되는 리소스를 미리 확인하고, 지난 시뮬레이션 보고서를 다시 볼 수 있습니다.

**GCP Network Connectivity Center:** 네트워크 연결 메뉴에서 NCC 허브를 조회·생성·수정·삭제하고 그룹, 스포크, 경로를 확인할 수 있습니다. 허브에 VPC 스포크 등을 추가하고 수정·삭제할 수 있습니다.

**비용 대시보드 계정별 보기:** 비용 대시보드에서 클라우드를 고른 뒤 계정을 선택하면 그 계정의 요약, 일별·월별 비용, 서비스별 비용만 볼 수 있습니다.

**AWS 기능 추가:** DynamoDB 테이블 즐겨찾기와 벡터 검색, EventBridge 아카이브 수정과 이벤트 재생, WAF 보호 팩의 사용자 지정 응답 본문 관리와 샘플 요청 확인, Secrets Manager 복제본 승격을 지원합니다. API Gateway REST API에서는 API 가져오기, 게이트웨이 응답 편집, CORS 활성화, SDK 생성을 할 수 있습니다.

### `change`

**미납 청구서 결제 순서:** 결제하지 않은 청구서가 여러 건이면 가장 오래된 청구서부터 결제됩니다. 더 오래된 미납 청구서가 남아 있으면 그 청구서를 먼저 결제하도록 안내합니다.

**청구 기간 경계 표시:** 비용 대시보드의 일별 비용은 오늘까지 최근 30일을 보여 주고, 청구 기간이 바뀌는 지점에 청구서 발행 표시를 합니다. 아직 집계 중인 달은 따로 표시하고, 새 기간 첫날에는 「집계 전」으로 안내합니다.

**납부 기한 표시:** 납부 기한을 미납 확정 전날 23:59(한국 시간)로 표시하고, 해외에서 보는 경우 현지 시각을 함께 보여 줍니다.

**리소스 시각 표시:** AWS·Azure·GCP 화면의 생성일·수정일 같은 시각을 각 클라우드 콘솔처럼 브라우저 시간대로 표시하고, UTC 기준 시차를 함께 보여 줍니다.

**Azure 리소스 만들기 흐름:** Azure 리소스를 만들면 배포 화면을 거치지 않고 바로 목록으로 돌아가며, 진행 상태와 결과를 알림으로 알려 줍니다.

**로그인과 화면 전환:** 로그인 후 대시보드로 더 빨리 이동하고, 화면을 준비하는 동안 로딩 화면을 보여 줍니다. 언어나 클라우드를 바꿔도 보던 화면과 입력한 값이 유지됩니다.

**클라우드 연동 진행 화면:** 연동 대기, 사용자 가져오기, AWS 멤버 계정 일괄 연동의 진행 화면을 더 간결하게 정리했습니다. 사용자 가져오기의 후보 목록이 만료되면 다시 찾도록 안내합니다.

### `fixed`

**자동 연동 로그인 실패 안내:** AWS 자동 연동에서 비밀번호나 인증 코드가 거절돼 앞 단계로 돌아와도 아무 안내가 없던 문제를 수정했습니다. GCP 자동 연동에서 실패 사유가 모두 같은 문구로 표시되던 문제도 수정했습니다.

**클라우드 연동 화면 로딩:** 연동 목록을 불러오는 동안 「연동된 클라우드가 없습니다」가 잠깐 보이던 문제를 수정했습니다. 해제된 계정을 영구 삭제하면 창이 바로 닫히고 진행 상태가 목록에 표시됩니다.

**사용자 가져오기 권한 안내:** AWS 하위 계정에서 사용자를 가져올 때 권한 안내가 두 번 표시되던 문제와 리전 이름이 칸 밖으로 넘치던 문제를 수정했습니다.

**청구서 증감률:** 청구 기간이 바뀌는 날 청구서와 대시보드에 「-100%」가 표시되던 문제와, 새 기간 첫날 아침에 일별 차트가 비어 있던 문제를 수정했습니다.

**GCP 프로젝트 라벨 저장:** 프로젝트 라벨을 저장한 뒤 한동안 다시 수정할 수 없던 문제와, 라벨을 모두 지워도 반영되지 않던 문제를 수정했습니다.

**Azure 작업 알림:** 역할 할당 추가·삭제, AKS 잠금, Service Bus 메시지 보내기 등에서 진행 알림이 빠지던 문제와, 공용 IP를 여러 개 삭제할 때 일부가 실패해도 성공으로 표시되던 문제를 수정했습니다.

**다국어 표시:** 영어·일본어 화면에서 일부 오류 메시지, 달력의 연월, 글자 수 초과 안내가 화면 언어로 표시되지 않던 문제를 수정했습니다.
