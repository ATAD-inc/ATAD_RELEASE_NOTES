# ODiiN 릴리즈 노트

## 2026-09-23

### `feature`

**Azure 가상 머신 전원 상태:** 가상 머신 목록에서 각 VM의 전원 상태(실행 중, 중지됨 등)를 바로 확인할 수 있습니다.

**Azure VMSS 영역 균형:** 가상 머신 확장 집합(VMSS)에서 가용 영역 간 균등 분산을 설정할 수 있습니다.

### `change`

**Azure 전원 버튼 상태:** 가상 머신과 VMSS의 시작, 정지 버튼이 실제 전원 상태에 맞게 활성화됩니다.

**Azure 가상 머신 상세 정보:** 가상 머신 상세에서 사용자 데이터와 OS 이미지 정보를 확인할 수 있습니다.

**Azure 디스크 성능 계층:** 디스크 상세에 성능 계층(P4, P6 등)이 표시되고, 성능 계층을 변경할 수 있습니다.

### `fixed`

**Azure NSG 연결 해제:** 네트워크 보안 그룹(NSG) 연결을 해제해도 반영되지 않던 문제를 수정했습니다.

**Azure VMSS 축소 정책:** VMSS의 축소 정책 설정이 저장되지 않던 문제를 수정했습니다.
