# ODiiN 릴리즈 노트

## 2026-09-16

### `feature`

**회원 유형별 가입:** 일반 회원, 개인사업자, 법인사업자 중 유형을 고른 뒤 유형에 맞는 약관 동의와 정보 입력을 진행합니다. 대한민국, 미국, 글로벌 가입을 지원합니다.

**사업자 확인:** 사업자번호로 국세청 사업자 상태를 확인하거나, 사업자등록증 PDF를 올리면 번호를 자동으로 읽어 입력합니다.

**사업 분야 등록:** 가입할 때 사업 분야를 선택할 수 있고, 설정 > 계정의 "사업자 정보" 탭에서 확인하고 변경할 수 있습니다. 변경은 조직 소유자와 관리자만 할 수 있습니다.

**담당 MSP 선택:** 가입할 때 담당받을 MSP를 선택할 수 있습니다(선택 사항). 기본 MSP가 아닌 곳을 고르면 해당 MSP가 승인한 뒤 연결됩니다.

**자동 로그인:** 로그인할 때 "자동 로그인"을 선택하면 7일 동안 로그인 상태가 유지됩니다. 선택하지 않으면 12시간 뒤 다시 로그인해야 합니다.

**남은 시도 횟수 표시:** 가입 중 인증번호 입력과 사업자 확인의 남은 시도 횟수를 보여 주고, 모두 사용하면 입력을 잠급니다.

**로그인·가입 화면 언어 전환:** 로그인과 가입 화면에서 한국어와 영어를 바꿔 볼 수 있습니다.

**MSP 연결 관리:** 설정 > MSP 연결에서 현재 담당 MSP를 확인하고 다른 MSP로 변경을 신청할 수 있습니다. MSP가 보낸 연결 요청은 내용을 확인한 뒤 승인하거나, 사유를 골라 거절할 수 있습니다.

**MSP 승인 대기 안내:** MSP 승인을 기다리는 동안 대시보드에 안내 배너가 표시됩니다.

**AWS ACM 인증서 관리:** 인증서 목록과 상세, 인증서 요청과 가져오기, 검증 메일 재전송, DNS 검증 레코드 생성, 삭제를 지원합니다.

**AWS KMS 키 관리:** AWS 관리형 키와 고객 관리형 키를 조회하고, 키 생성, 키 정책 편집, 별칭과 태그 관리, 키 교체, 활성화와 비활성화, 삭제 예약을 할 수 있습니다.

**AWS EFS 파일 시스템:** 파일 시스템 목록과 상세, 빠른 생성과 단계별 생성, 편집, 파일 시스템 정책, 탑재 대상, 복제를 관리할 수 있습니다.

**AWS Route 53 호스팅 영역:** 호스팅 영역 생성, 편집, 삭제와 레코드 생성, 수정, 삭제, 영역 파일 가져오기를 지원합니다.

**표 컬럼 너비 자동 맞춤:** 표의 컬럼 경계를 더블클릭하면 내용 길이에 맞춰 너비가 조정됩니다.

### `change`

**멤버 초대 방식:** 멤버 초대가 "계정 발급" 방식으로 바뀌었습니다. 초대받은 분은 메일 링크에서 비밀번호를 설정해 바로 합류합니다.

**개인 조직 이름:** 개인 조직 이름이 이메일 아이디로 표시되어, 이름이 같은 조직을 구분하기 쉬워졌습니다.

**초대 링크 오류 안내:** 만료되었거나 잘못된 초대 링크로 들어오면 그 사유를 알림으로 안내합니다.

**MSP 연결 신청 권한:** MSP 연결 신청은 조직 소유자와 관리자만 할 수 있습니다.

**MSP 연결 충돌 안내:** 이미 다른 MSP가 담당 중이거나 처리 중인 연결 신청이 있으면 사유를 안내하고, 남은 신청을 취소할 수 있습니다.

**회원가입 인증 메일:** 인증 메일을 새 디자인으로 바꾸고 한국어와 영어로 제공합니다. 인증번호 오류는 불일치와 만료를 구분해 안내합니다.

**Azure 생성 화면 입력 확인:** 가상 머신, 커스텀 이미지 VM, VMSS 생성 화면에서 필수 항목을 미리 확인하고 안내합니다.

**메뉴와 화면 정리:** 왼쪽 메뉴에서 하위 항목을 고르면 상위 메뉴도 함께 강조되고, 일부 목록과 생성 화면의 정렬을 다듬었습니다.

**보안 강화:** 회원가입과 초대 과정의 보안을 강화했습니다.

### `fixed`

**비밀번호 재설정:** 비밀번호 재설정이 되지 않던 문제를 수정했습니다.

**가입 중 화면 이동:** 가입 도중 로그인 화면으로 이동되거나, 일시적인 네트워크 오류로 입력 중인 가입 정보가 사라지던 문제를 수정했습니다.

**가입 후 로그인·로그아웃:** 가입을 마친 뒤 로그인하면 이전 계정의 대시보드가 보이던 문제와 로그아웃 버튼이 반응하지 않던 문제를 수정했습니다.

**MSP 연결 상태 표시:** MSP 연결 상태를 불러오지 못했을 때 "미연결"로 잘못 표시되던 문제를 수정했습니다.

**AWS 예상 비용:** 월말에 AWS 홈의 예상 비용이 표시되지 않던 문제를 수정했습니다.

**AWS KMS 키 선택 목록:** AMI 복사와 S3 복제 규칙 화면에서 KMS 키 목록이 비어 있던 문제를 수정했습니다.

**Azure NAT 게이트웨이 공용 IP 해제:** NAT 게이트웨이에서 공용 IP를 모두 해제해도 반영되지 않던 문제를 수정했습니다.

**Azure VMSS 동작:** VMSS의 시작, 다시 시작, 정지가 동작하지 않던 문제와 VMSS 생성이 실패하던 문제를 수정했습니다.

**Azure 가상 머신 상세:** 상세 화면에서 일부 정보가 비어 보이거나 잘못 표시되던 문제와, 데이터 디스크 연결 후 목록이 갱신되지 않던 문제를 수정했습니다.

**Azure 커스텀 이미지 버전:** 버전 정렬과 "최신" 표시가 맞지 않던 문제를 수정했습니다.

**Azure 가상 네트워크:** 피어링 사전 검증 누락, 주소 공간이 비어도 저장되던 문제, NSG 작업 중 진행 표시가 나오지 않던 문제를 수정했습니다.

### `removed`

**조직 편입 신청, 하위 그룹, 받은 초대 수락:** 세 기능을 종료했습니다. 계정은 하나의 조직에만 소속되며, 새 멤버는 조직 관리자가 "계정 발급" 방식으로 초대합니다.
